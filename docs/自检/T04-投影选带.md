## 3. 实现规则与编号

- CGCS2000 3°GK 带号版 EPSG:4513–4533（zone 25–45）；无带号版 EPSG:4534–4554（CM 75E–135E）。徐州 `zone=39`、`CM=117` → 无带号 `4548`；带号版为 `4527`，假东 `39 500 000 m`。
- 带界取整用 `floor(lon / 3 + 0.5)`，115.5°E 归入较高带（CM 117），避免 Python 银行家舍入把边界分到低带。
- 单带判定：图幅经度跨度 ≤ 一个 3° 带宽（3°）。徐州示例 bbox `116.2–118.6` 跨度 2.4°，虽右边界略超 CM 117 带的 115.5–118.5，仍按单带处理并取中心经度 117.4° 选带。该阈值是实现规则，`facts/02` 未给量化值，已在此记录。
- 输出白名单：`EPSG:4490`、3°GK（4513–4533 / 4534–4554）、WGS84 UTM（32601–32660 / 32701–32760）、`EPSG:3857`。WGS84 地理（4326）不在白名单；Albers 仅用于内部量算，不作为输出。
- Web Mercator 调 `ensure_measure_allowed` 直接抛错。
- 变换链：`plan_transform` 记录源/目标名称与 EPSG、pyproj 操作描述、是否含基准转换。WGS84→CGCS2000 会标记「含基准转换」。
