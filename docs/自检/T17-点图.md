## 3. 关键设计

- **面积（s）线性映射，不用半径**：`scatter` 的 `s` 是面积，`size_map` 按 `(v - vmin)/(vmax - vmin)` 线性映射到 `[S_MIN=20, S_MAX=800]`，避免半径线性带来的视觉夸张。退化（全相同 / 全 NaN）回退 `FALLBACK_SIZE=200`。
- **缺测点灰色空心 + 计数**：缺测（None / NaN）单独一次 `scatter(facecolors="none", edgecolors=MISSING_EDGE)`，与有效点分开绘制，计数进 `missing_count`。
- **图例双份**：断点图例复用 T15 `apply_layout`（与 T16 同源的 `legend_labels` / `palette_colors`）；气泡大小另画三级示意（最小值 / 中值 / 最大值），用 `markersize=sqrt(面积)` 保持面积比例。
- **图例全部外置**：气泡大小图例放图框外右侧（`bbox_to_anchor=(1.02, 0.4)`）、断点图例在其上方（`legend_anchor=(1.02, 1.0)`），几何断言确认两者都在图框外且互不重叠，避免压住右下角气泡。
- **几何解耦**：渲染层不读 CSV、不聚合、不插值；只接收已带坐标系、几何为 Point 的 GeoDataFrame。坐标系缺失、几何非点、数值字段/标注字段缺失均抛 `DataError`，不静默降级。
- **`render` 总入口**：`render(spec, gdf, **kwargs)` 按 `map_type` 分派；未实现图种抛 `NotImplementedError`，与 SPEC「五类封顶」一致。
