## 3. 关键设计

- **字体**：`fonts.py` 只做「注册 + 选字体 + 设 rcParams」，返回实际采用的字体名；`apply_layout` 每次出图前调用 `load_chinese_font()`，保证中文不依赖系统环境。
- **CRS 不写死**：坐标注记读 `MapSpec.crs`，spec 写什么标什么（spec 默认 `EPSG:4490`，见 `spec.py`）。比例尺换算所需的 `metric_extent(source_crs=...)` 是 bbox 自身坐标系（输入侧，GeoJSON 约定 WGS84），与输出坐标系 `spec.crs` 严格区分，二者互不耦合。
- **版式要素与地图主体解耦**：本模块只画版式要素，不画地图主体；地图主体由 T16–T18 各自渲染后与本模块组合。
- **四项不代填**：图名（第 1 条）、分级方法与级数（第 6 条）、配色语义（第 8 条）、缺失值说明（第 10 条）全部只读 spec；其余版式要素（图例分组、比例尺、指北针、来源注记、坐标注记）由渲染层补齐，与 facts/07 一致。
- `apply_layout` 返回 `LayoutReport`（drawn / scale_bar_label / font / summary），供界面回显与测试核对。

## 4. 已知项与未做

- **可变字体 weight 警告**：`NotoSansSC.ttf` 是可变字体（VF），matplotlib 会提示 `Failed to find font weight normal ... now using 100`，仅影响粗细不精确，不影响字形与中文显示。后续优化项（不阻塞）：可换 9.7 MB 的 `simhei.ttf`（黑体，覆盖 GBK 常用汉字，但微软版权字体、分发有授权顾虑），或对 Noto 做字符子集化缩小体积。

- 未接入 `qa_check`、Agent 提示词与 `loop.py`。
