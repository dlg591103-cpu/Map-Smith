## 4\. 实现规则记录

-   **插值判定**：`n_valid < 3` → `reject`；`n_valid < 10` → `degrade`；`cover` 缺失或 `< 0.5` → `degrade`；其余 → `idw`。
-   **覆盖度**：站点凸包与研究区求交后取面积，除以研究区面积，结果裁剪到 `[0, 1]`；在 `projection.choose_measurement_crs` 选出的度量投影下计算，投影结果写入 `DataProfile.measurement_crs`。
-   **缺研究区**：`cover=None`，按规则保守降级，理由写「无法计算（缺少研究区边界）」，不当作通过。
-   **理由三行**：站数与阈值、覆盖度与阈值、结论，可直接写入 `MapSpec.notes`。
-   **CRS 闸门**：`parse_upload` 只标记 `crs_status`，`ensure_crs` 在未确认时抛错；GeoJSON 无 `crs` 成员时按 RFC 7946 给建议值 `EPSG:4326`，但必须用户确认。
-   **DataV 纠偏**：`load_admin` 默认 `source_is_gcj02=True`，用公开近似算法纠偏到 WGS84，方向与特征数写入 `meta["transform"]`；实测若来源不是 GCJ-02，只关此开关，不散落改坐标。
-   **字段口径**：站点标准列 `station_code/station_name/city/lon/lat`；指标标准名 `PM2_5_24h`、`PM10_24h`、`NO2_24h`、`SO2_24h`、`O3_8h_24h`、`CO_24h`、`AQI`，与 `MapSpec` 示例一致。
