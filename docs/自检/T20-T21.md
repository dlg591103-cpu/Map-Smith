## 3. 关键设计

1. **依赖注入**：`load_fn` / `map_fn` / `render_fn` / `review_fn` 全部由调用方传入。编排不绑定 LLM、网络与 matplotlib，测试可用替身覆盖每条分支。
2. **终止态只有三种**：`rendered`、`needs_input`、`failed`。`decision == "reject"` 回到 `needs_input`，不产出 spec。
3. **计时归属**：单一 `clock()` 从 `run()` 入口起算，`remaining()` 传给 reviewer 作为单轮上限，符合 facts/04「按整体 60 秒计，不是每环节各 60 秒」。
4. **返工补丁**：只取 `issues[0]["fix_spec_patch"]`，经 `apply_spec_patch()` 应用，避免整份 spec 重写导致不可对比。
5. **不重复实现 reviewer 的轮次逻辑**：`allow_render` 以 reviewer 返回值为准，`deny_limit` 仅作编排层保护，测试可用替身验证。
