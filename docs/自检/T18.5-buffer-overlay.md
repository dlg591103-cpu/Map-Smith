## 3. 关键设计

- **组合层复用，不复制 layout**：`compose.py` 复用 `choropleth._transformed_extent` / `_aspect_for`（重投影范围与宽高比）、`extent.drawing_extent`（buffer 取景收窄）、`layout.palette_colors`（配色）、`layout.apply_layout`（版式要素）、`point` 的点样式常量。buffer/overlay 没有任何自己的图名/比例尺/指北针/注记逻辑。
- **图例归属**：buffer/overlay 的 `spec.classification=None`，`apply_layout` 因此不画分级图例；自定义图例（buffer 半径、overlay 两图层）由 compose 自己画，外置 `bbox_to_anchor=(1.02, 1.0)` 不压内容。
- **buffer 图层顺序**：缓冲面 `zorder=1`（`alpha=0.30` + 描边）→ 原始要素 `zorder=2`（只描边不填充，linewidth 0.8）→ 站点 `zorder=3`（沿用 point 颜色），三层不互相覆盖。
- **overlay 可分辨**：底层 `palette[0]`（浅色）+ 上层 `palette[1]`，两层 `alpha=0.50`，上层描边，交叠区为两色混合。
- **半径不写死**：`buffer_km` 参数优先，其次 `gdf.attrs["buffer_km"]`；两者皆无则图例退化为「缓冲区」泛称。半径只用于图例注记，不参与几何计算（缓冲几何由 `tools.analyze.buffer_layer` 产出）。

## 4. 已知项与未做

- **半径来源的契约缺口**：`spec.Layer` 无「缓冲半径」字段（`spec.py` 禁止改），故半径经函数参数 `buffer_km` 或 `gdf.attrs["buffer_km"]` 传入，而非「从 spec 读」。若要求半径进入 MapSpec，属跨模块契约变更，需与 core 侧确认。
- **overlay 图例标签语义**：`_layer_label` 按 `name` 列 → `adcode` 列 → spec 图层 id 兜底。真实数据里上层（站点缓冲面）只有 `station_name` 列、无 `name`/`adcode`，故图例上层显示 spec 图层 id（如 `data`），不够语义化。方案要求「用图层 name/adcode」，数据缺 name/adcode 属数据侧命名问题。
- **交叠区可辨识的判据局限**：用「两层颜色相异 + alpha 混合」的颜色断言证明可分辨；未做「交叠区像素颜色等于两色混合」的像素级断言（`analyzeImage` 对本模型返回空，无法目视），以 `frame_content_ratio` 量化内容占比作为替代（buffer 0.186、overlay 0.382）。
- **未接界面 / loop**：`ui.build_spec` 仍只开放 choropleth/point/idw，本任务只补 render 分派，不改界面图种白名单。
- 未合并回 `main`、未执行独立验收。
