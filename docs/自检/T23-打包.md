## 3. 关键设计

- **断网可跑**：demo_data 位于 `src/mapsmith/demo_data/`，随 `src` 一并 `COPY`/打 zip，启动不联网；`pyproj==3.8.0` 的 wheel 自带 `proj.db`，无需运行时下载 PROJ 数据。
- **只装 lock 依赖**：`pip install -r src/requirements.lock`（pip freeze 产物，版本锁死可复现），不装 lock 之外的包。
- **启动命令统一**：`python -m streamlit run src/mapsmith/app.py --server.port 8501`（与 T22 自检记录一致）；端口经 `PORT` 环境变量覆盖，出图/数据路径经 `MAPSMITH_OUTPUT_DIR` / `MAPSMITH_DEMO_DATA_DIR` 覆盖。
- **两个实测发现的坑（均已修复并验证）**：
  1. **email onboarding 阻塞**：`server.headless` 在 Windows 默认 false（`IS_LINUX_OR_BSD and not DISPLAY`），首次启动弹「Email:」询问阻塞监听。用 `STREAMLIT_SERVER_HEADLESS=true` + `STREAMLIT_BROWSER_GATHER_USAGE_STATS=false` 跳过，不改启动命令。
  2. **mapsmith 无法 import**：streamlit 只把脚本父目录 `src/mapsmith/` 加入 sys.path，`from mapsmith.config` 会 `ModuleNotFoundError`。用 `PYTHONPATH=src`（容器内 `/app/src`）解决，不改启动命令。
