## 3. 关键设计

1. **LLM 只决策，不计算**：`cartographer` 只返回 method/n/配色等决策；`bbox`、`breaks`、`data_source_note`、`crs` 由 `flow` 本地补齐，`breaks` 统一走 `ui.compute_breaks`。
2. **阶段流**：`flow` 提供 `on_stage` 回调，`server` 用线程 + 队列实时转 SSE；每个阶段只发一次，避免返工重复推送。
3. **上传与 CRS**：`/api/upload` 先解析并返回 `crs_status`；缺 CRS 时 `/api/chat` 返回 `crs_required`，前端弹窗确认后重新提交，不静默默认 4326。
4. **面/点分流**：点数据走 `profile_points` 与 point/idw；面数据走面图层统计与 choropleth；统计表明确拒绝。
5. **返工 spec 兼容**：`loop` 返工后的 spec 是 dict，可能带审查补丁字段（如 `classification.unit`）；`_to_mapspec` 渲染前过滤为合法 `MapSpec`，审查仍能看到补丁字段。
6. **解除 Streamlit 依赖**：删除 `app.py` 与冒烟测试，`ui.py` 保留纯函数；`web/dist` 通过 `.gitignore` 例外入库。
7. **点图底色与指北针**：`render_point` 接受 `background_gdf`，散点前画浅灰行政区面；指北针移到图框左侧外，避免收窄取景后压住气泡。
8. **AQI 强制六级**：`flow` 对 `field="AQI"` 强制 `custom / n=6 / [50,100,150,200,300,None] / AQI6 / 无量纲`；`palette_colors` 返回国标六色；`qa_check` R06 允许 custom 末项 None。
9. **模型输出约束**：请求带 `response_format=json_object`，payload 给出 `output_schema` 与 `format_instruction`；解析失败时保留原文片段报中文错误。模型给的标注字段（如「站点名」）映射到实际列 `station_name`，失败则关闭标注而不是让渲染崩。
