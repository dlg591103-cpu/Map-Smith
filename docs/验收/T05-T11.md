### 5.3 观察项（建议后续统一）

1. `docs/facts/02-范围与边界.md` 的 diff 含大量与本次无关的缩进、链接 URL 编码重排，扩大了审查面；实质新增只有「数据源坐标系（2026-11-09 确认）」一条，建议事实文档避免无关格式化。
2. `uploads.py` 的 CSV 分支把「排除坐标/名称/编码/城市后的所有列」都算作可用指标列，未过滤数值类型；GeoJSON 与 Shapefile 分支则按数值类型过滤，三处口吻不一致，CSV 含文本备注列时会误报指标数。
3. `load_layer.py` 把 `AQI` 与 `_24h` 字段并作「取当日最后一个有效观测」；facts/06 说 quotsoft 的 AQI 以小时值提供，该聚合口径建议在 T20 prompt 或渲染层明确，避免 AQI 被当成 24 小时均值。
4. `load_air` 按 `city.str.contains(city_bare)` 过滤，城市名互为子串时可能多匹配；当前离线数据未触发，建议加全名优先匹配。
5. DataV 与 quotsoft 的联网分支仍受沙箱出站限制，未在真实网络验证；与 facts/06「可用性未证实」一致，属已声明边界，不作为本模块缺陷。
