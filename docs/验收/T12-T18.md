## 5. 问题清单

### 5.1 非阻塞问题

1. **17.7 MB 字体入库**：`src/mapsmith/render/fonts/NotoSansSC.ttf` 随代码提交，`git clone` 需拉取该体积。是否改用 Git LFS 或运行时下载，需在后续版本统一决策；当前方案满足断网可用，暂不判缺陷。
2. **jenks 走纯 Python**：环境未安装 `numba`，`mapclassify` 分级触发 `UserWarning: Numba not installed`。功能正确，性能未优化，属依赖可选项。
3. **与审图员尚未联调**：`render_meta`（`scale_bar`、`north_arrow`）与 `font.sans_serif` 是否按 [T19 审图员契约](../Spec/T19-审图员契约.md) 第 2 节字段真实写入 `MapSpec`，尚未验证；R03/R04/R09 的真实回执判定依赖此项。
4. **T10 遗留承接**：T05–T11 验收中 T10「覆盖 IDW 样例」为有条件通过，`demo_data/` 仍无 `n ≥ 10` 且 `cover ≥ 0.5` 的城市数据。T18 自身由构造用例覆盖，但 SPEC 第 7 节「断网完成全流程」尚未具备真实 IDW 数据条件。
