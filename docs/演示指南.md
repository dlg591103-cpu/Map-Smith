# MapSmith 演示指南

> 面向比赛评委 / 演示者。MapSmith 的核心是「说一句话（或上传一份数据）→ 出一张符合制图规范的专题图」，依据 facts/01「一句话定义」与 SPEC 第 7 节验收第一条。
> 对应版本：**v0.1.x**。

## 两种出图入口

| 入口 | 是否依赖 LLM | 定位 |
| --- | --- | --- |
| 对话生成 | 是 | **核心入口**：一句话出图，三 Agent 自动完成解析→制图→审查 |
| 高级表单 | 否 | 补充入口：上传数据 / 手动指定参数，离线兜底 |

---

## 1. 对话生成（核心入口）

产品核心能力（facts/01「一句话定义」；SPEC 第 7 节「一句话（区域 + 指标 + 时间）可出图，无人工干预」）。对话入口依赖 LLM，演示前需先完成 1.1 的配置。

### 1.1 前置：配置 LLM（二选一）

对话需要三项配置：`MAPSMITH_LLM_BASE_URL` / `MAPSMITH_LLM_API_KEY` / `MAPSMITH_LLM_MODEL`。
读取优先级：**环境变量 > 项目根 `.env` 文件**（`KEY=VALUE`，值不带引号）。

**方案 A：本地 Ollama（事实：默认配置，离线可用）**

```bash
# 1. 安装 Ollama：https://ollama.com/
# 2. 拉取模型并启动
ollama pull qwen2.5:3b
ollama serve
```

默认配置即为 `http://127.0.0.1:11434/v1` + `qwen2.5:3b`，无需改文件。
评委现场不依赖网络，最稳。

**方案 B：外部 API（以 DeepSeek 为例）**

在项目根新建 `.env`（可复制 `.env.example`）：

```bash
MAPSMITH_LLM_BASE_URL=https://api.deepseek.com/v1
MAPSMITH_LLM_API_KEY=sk-xxx          # 替换为自己的 key
MAPSMITH_LLM_MODEL=deepseek-chat
```

> Ollama 未安装 / 未运行、或外部 key 无效时，对话出图会失败（返回 502 或「本地模型未启动」）；**高级表单不受影响**。

### 1.2 一句话出图示例

| 输入 | 期望结果 |
| --- | --- |
| 「徐州 2026-11-01 的 PM2.5 分布图」 | 数据管家解析出区域/时间/指标；制图师判定站点有效值仅 5 个（< 10 成面阈值），**自动降级为点图**，在图/报告中给出三行理由（站数 / 覆盖度 / 结论）；审图员 PASS，出图 + 制图说明 + 审查意见 |
| 「徐州 2026-11-01 的 PM2.5 等值面图」 | 若满足成面条件则 IDW 插值；否则同上降级为点图 |

> 徐州站点稀疏自动降级为点图是**正确行为**，不是故障（两档判定规则见 facts/04）。

## 2. 高级表单（离线兜底 / 上传数据）

不依赖 LLM，demo_data 离线可出图，五种图种齐全。用于：断网现场兜底、上传自有数据出图。

### 启动

```bash
# Windows：run.ps1；Linux/macOS：run.sh
# 首次运行会自动创建 .venv 并安装依赖，之后启动 Web 服务
bash run.sh          # 默认 http://127.0.0.1:8501
```

浏览器打开 `http://127.0.0.1:8501`，进入「高级表单」。

### 数据准备：预热需要的日期（重要）

默认**联网是开着的，但语义是「离线优先」**：`demo_data/air/` 有该日期就用本地，
缺了才联网下载。但 quotsoft 实测下行约 **12 KB/s**，单日文件（约 1.5 MB）要
**130 秒左右**，所以在对话里等首次下载体验很差 —— 演示前先预热：

```bash
# 最近 7 天（截至前天；quotsoft 凌晨才更新前一日）
python warmup_data.py

# 最近 14 天
python warmup_data.py --days 14

# 指定区间 / 指定若干日期
python warmup_data.py --from 20261101 --to 20261110
python warmup_data.py 20261101 20261103
```

Windows 也可直接双击 `warmup-data.cmd`，按提示输入天数。
下载成功会落盘到 `demo_data/air/`，之后同一日期**断网也能用**。

> 现场断网演示时设 `MAPSMITH_OFFLINE=1` 启动服务可**强制离线**，省去每次等下载超时。
> 联网默认是开着的，本地有数据时不会发起任何网络请求。

### 场景 2：上传面数据做 choropleth 分级设色

| 项 | 值 |
| --- | --- |
| 数据 | 上传一个带数值字段的面图层（GeoJSON 或 Shapefile zip，含 `.prj`） |
| 图种 | choropleth |
| 期望结果 | 面要素按数值字段分级设色，图例显示分级断点；缺测面用中性灰填充并计入缺失 |

> 上传面数据若未声明坐标系，界面会先弹出确认框，确认后才继续（不静默假定）。

#### 可直接用的示例数据：徐州市各区县 PM2.5

`demo_data/choropleth/xuzhou_district_pm25_20260115.geojson` —— 10 个区县面，含
`PM2_5_24h` 数值字段（全部有值，能做满色块图）。

| 项 | 值 |
| --- | --- |
| 上传文件 | `src/mapsmith/demo_data/choropleth/xuzhou_district_pm25_20260115.geojson` |
| 指标 | PM2.5 |
| 图种 | choropleth |
| 分级方法 | 等间距 / 5 级 |

**数据来源（真实，非构造）**：徐州市生态环境局《徐州市各县（市）区空气质量情况
（2026 年 1 月 1 日—1 月 15 日）》。
**口径**：`PM2_5_24h` 存的是该时段**累计浓度**（μg/m³），不是单日值；官方表中的
「经开区」是功能区、不是行政区，demo 边界无对应面，故未纳入。

> 为什么需要这份数据：quotsoft 站点数据在徐州只有 11 个站且全在市区（覆盖约 2%），
> 按两档判定会降级为点图，做不出「全市每个区县都有色」的分级设色图。这份区县级
> 官方数据用于演示 choropleth 的完整形态；两者口径不同，勿混用。

#### 上传自己的统计数据（GDP / 人口 / 任何指标）

不需要先转成面图层：直接上传一份**「行政区名 + 数值」的 CSV**，系统会自动识别
行政区名列、关联边界、出分级设色图。

格式（UTF-8，首行表头）：

```csv
district,gdp,population
鼓楼区,520.5,38.2
云龙区,610.2,42.1
铜山区,1542.0,120.5
```

| 要点 | 说明 |
| --- | --- |
| 行政区名列 | 值必须与边界里的 `name` 对得上（如「鼓楼区」「铜山区」），匹配率需 ≥50% |
| 数值列 | 可以有一个或多个；表单里选的指标若不在表里，会自动挑数值列并在摘要写明选了哪列 |
| 缺测 | 没写数值的区县留空即可，图上用中性灰并计入缺失 |
| 操作 | 高级表单 → 上传该 CSV → 区域填「徐州」→ 图种 choropleth → 生成地图 |

> 数据来源自行负责：区县 GDP / 人口没有统一的免费开放接口（国家统计局以省市为主，
> 区县多在各地统计年鉴里），本项目**不生成任何示意值**。请用统计年鉴 / 地方统计公报
> 的原始数字。

#### 直接画 GDP（内置的江苏各市数据集，无需上传）

`demo_data/stats/320000_gdp_2025q3.csv` 内置了**江苏 13 个设区市 2025 年前三季度 GDP**
（数据来源：江苏省统计局，经新华财经/聚汇数据公开发布整理，单位亿元）。

| 项 | 值 |
| --- | --- |
| 区域 | 江苏 |
| 指标 | GDP |
| 图种 | choropleth |
| 期望结果 | 13 个设区市按 GDP 分级设色（19930 亿 ~ 3318 亿），边界从 DataV 联网取 |

操作：高级表单 → 区域填「江苏」→ 指标选「GDP」→ 图种 choropleth → 生成地图。
**不需要上传任何文件**；第一次运行会联网取江苏 13 市边界（约 100 KB）。

> 扩展方式：想支持别的省份/指标，把同格式 CSV 放进
> `src/mapsmith/demo_data/stats/{adcode}_{指标名}.csv` 即可（如 `320100_gdp.csv`），
> 指标名用 `gdp` / `population`；数据须为真实公开统计。

## 3. key 安全提示

- API key 是**计费资源**，不要提交到仓库、不要写进 zip。
- `.env` 已在 `.gitignore` 中（不入库、不进 zip）；仓库只提供 `.env.example` 模板（占位符，无真实 key）。
- 演示建议使用**额度小的专用 key**，并设置限额。

---

## 4. 版本与状态

- 本指南对应 **v0.1.x**。
- **对话生成是核心入口**，需配置 LLM（本地 Ollama 或外部 API）；高级表单是离线兜底与上传数据入口。
- 若未配置 LLM，仅对话入口不可用，高级表单仍可离线出图。
