# 架构与决策原则

> 状态：已确认（2026-11-05）。本文件负责整体架构与核心设计原则。

## 三层架构

```
用户一句话（+ 可选数据文件）
        │
        ▼
① 编排层：三 Agent 循环（对话 / 决策 / 返工）
        │ 产物
        ▼
② 决策层：MapSpec（JSON）
   图种 / 分级方法 / 配色 / 注记 / 版式 / 数据源声明
        │
        ▼
③ 渲染层：确定性代码把 spec 变成图（不含任何 LLM）
        │
        ▼
PNG / PDF + 制图说明 + 审查意见
```

## 核心原则

**LLM 只做决策，不做计算、不写绘图代码。** 分级算法由 `mapclassify` 计算，出图由 `matplotlib` 绘制，LLM 只负责「选哪种方法、为什么选」。

这一原则同时解决三个问题：

- **可解释**——追问细节时能定位到具体环节。
- **可增量修改**——改 spec 一个字段就重渲染，几秒出新图。
- **可测**——spec 是 JSON，不同版本能 diff。

## 反面做法

让 LLM 生成绘图代码再 `exec` 执行：不可解释、不可控、出错无法定位。
