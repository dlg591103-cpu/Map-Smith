# 数据源与离线兜底

> 状态：已确认（2026-11-05）。本文件负责数据来源；外部接口的实际可用性尚未在本机核验。

## 数据来源

| 数据 | 来源 | 备注 |
| --- | --- | --- |
| 行政边界 | 阿里 DataV GeoAtlas（按 adcode 取 GeoJSON） | 免费；2026-11-18 实测可用（南京/无锡/苏州/江苏均 200） |
| 空气质量 | `quotsoft.net` 的 `https://quotsoft.net/air/data/china_sites_[YYYYMMDD].csv`（全国城市为 `china_cities_[YYYYMMDD].csv`） | 2026-11-17 实测返回 200；下行约 12 KB/s，单日约 1.5 MB |
| **社会经济统计（GDP / 人口）** | **无统一开放接口**：国家统计局接口有反爬（实测 403），区县数据分散在各地统计年鉴/公报 | 走「预置数据集」或「用户上传 CSV」两条路，见下 |
| POI / 路网 | OSM Overpass API | 免费、无需 key |
| 离线兜底 | 内置徐州多日空气质量 + 江苏各市 GDP 到 `demo_data/` | 现场断网也能演示 |
| 用户上传 | 本地 CSV / GeoJSON / Shapefile(zip)，可附加 GeoTIFF 底图 | 格式与 CRS 规则见 [02-范围与边界.md](02-范围与边界.md)；统计表会自动关联行政区 |

## 社会经济统计数据（GDP / 人口）怎么来

**结论：没有可靠的「程序自动联网获取」通道**，2026-11-18 实测：

- 国家统计局 `data.stats.gov.cn` 数据接口 → **403 Forbidden**（反爬，需 cookie/JS 逆向，不稳定）
- 免费搜索引擎 HTML 直连 → Bing 只返回百科/政府首页（无数据表），搜狗/百度返回验证页
- 只有指向已知数据站的具体页面才能抓到（如聚汇数据经新华财经转载的表格）

因此提供三条路径，按可靠性排序：

1. **预置数据集（推荐）**：`demo_data/stats/{adcode}_{指标}[_期次].csv`，如
   `320000_gdp_2025q3.csv`（江苏 13 市 2025 前三季度 GDP，来源江苏省统计局）。
   用户填「江苏 / GDP」即可直接出图，不联网、不猜测。
2. **用户上传 CSV（兜底）**：任意「行政区名 + 数值」表格，系统自动识别行政区名列、
   关联边界后出图。
3. **联网搜索（实验性，默认关闭）**：设 `MAPSMITH_SEARCH_ONLINE=1` 才启用
   `tools/web_stats.py` 的「搜索 → 抓取 → LLM 抽取 → 地区名校验」链路；命中率低，
   失败会明确报错并提示改用上传，**绝不编造数字**。

> 注意：这些数据没有「自动获取」的稳定方案，本项目也不会生成示意值。
> 预置数据的扩展方式见 `docs/演示指南.md`。

## quotsoft 数据细节

- 提供 AQI / PM2.5 / PM10 / SO2 / NO2 / O3 / CO 的 1 小时值与 24 小时值。
- 站点列表文件含：监测点编码、名称、所属城市、经度、纬度——有经纬度即可做空间插值。
- 全局 UTF-8 编码。
- 每日凌晨 2 点后更新前一日数据。
- 无底图也可出图：白底 + 行政边界，学术专题图常用这种版式，少一个崩溃点。

## 底图策略

不接在线底图服务（Contextily 之类需联网，现场风险高）。允许用户上传 GeoTIFF 作离线底图，仅显示、不做栅格分析与重投影。

## 联网取数开关（2026-11-18 调整）

- **默认联网开启，但语义是「离线优先」**：本地 `demo_data/` 有该日期/边界就直接用，
  绝不为了联网而联网；只有本地确实缺的时候才回落到 quotsoft / DataV 在线下载。
- 下载成功会**落盘缓存**到 `demo_data/air/china_sites_YYYYMMDD.csv`，之后同一日期
  断网也可用。联网失败仍抛明确错误，不伪造数据。
- 设环境变量 `MAPSMITH_OFFLINE=1` 可**强制离线**（现场断网演示时用，省去每次等下载超时）。

### 下载速度实测（重要）

2026-11-18 实测 quotsoft 下行约 **12 KB/s**，单日全国站点 CSV 约 1.5 MB，
**完整下载要 130 秒左右**。因此：

- 不要指望在对话里等首次下载完成（虽然会成功，但体验很差）；
- 演示前用 `warmup_data.py` 提前把要用的日期批量预热到 `demo_data/air/`；
- 现场演示建议设 `MAPSMITH_OFFLINE=1`，完全走本地缓存。
