# 数据源与离线兜底

> 状态：已确认（2026-11-05）。本文件负责数据来源；外部接口的实际可用性尚未在本机核验。

## 数据来源

| 数据 | 来源 | 备注 |
| --- | --- | --- |
| 行政边界 | 阿里 DataV GeoAtlas（按 adcode 取 GeoJSON） | 免费 |
| 空气质量 | `quotsoft.net` 的 `https://quotsoft.net/air/data/china_sites_[YYYYMMDD].csv`（全国城市为 `china_cities_[YYYYMMDD].csv`） | 用户提供信息：曾实测返回 HTTP 200（未在本机复核）；完整路径见 quotsoft 下载页 |
| POI / 路网 | OSM Overpass API | 免费、无需 key |
| 离线兜底 | 内置 2026-11-01 徐州全量数据到 `demo_data/` | 现场断网也能演示 |
| 用户上传 | 本地 CSV / GeoJSON / Shapefile(zip)，可附加 GeoTIFF 底图 | 格式与 CRS 规则见 [02-范围与边界.md](02-范围与边界.md) |

## quotsoft 数据细节

- 提供 AQI / PM2.5 / PM10 / SO2 / NO2 / O3 / CO 的 1 小时值与 24 小时值。
- 站点列表文件含：监测点编码、名称、所属城市、经度、纬度——有经纬度即可做空间插值。
- 全局 UTF-8 编码。
- 每日凌晨 2 点后更新前一日数据。
- 无底图也可出图：白底 + 行政边界，学术专题图常用这种版式，少一个崩溃点。

## 底图策略

不接在线底图服务（Contextily 之类需联网，现场风险高）。允许用户上传 GeoTIFF 作离线底图，仅显示、不做栅格分析与重投影。
