# 范围与边界

> 状态：已确认（2026-11-05）。本文件负责「做什么 / 不做什么」与投影边界，变更需用户显式提出。

## 五类图种（封顶，不再扩）

1.  分级设色图（choropleth）
2.  点图 / 气泡图（含站点标注）
3.  缓冲区分析图（buffer）
4.  空间叠加 / 裁剪结果图（overlay / clip）
5.  IDW 空间插值面（仅当自适应判定通过时启用，判定规则见 [04-三Agent与协作协议.md](04-%E4%B8%89Agent%E4%B8%8E%E5%8D%8F%E4%BD%9C%E5%8D%8F%E8%AE%AE.md)）

## 明确不做

-   栅格分析（裁剪、拉伸、重采样等）；仅支持栅格底图显示
-   地图服务发布
-   数据管理平台
-   自定义投影定义与参数微调（2026-11-05 起取代原「任意投影变换」的表述）

## 输入数据格式（2026-11-05 确认）

| 类型 | 格式 | 说明 |
| --- | --- | --- |
| 矢量 | Shapefile（`.shp` / `.shx` / `.dbf` / `.prj` 打包为 zip）、GeoJSON、CSV（点位 / 统计表，UTF-8） | Shapefile 必须整体上传，不能只传 `.shp` |
| 栅格 | GeoTIFF | **仅作离线底图显示**，不做栅格分析与重投影；CRS 与出图坐标系不一致时提示不支持自动配准，不静默叠加 |

坐标系：按下文输入侧规则处理。文件未声明 CRS 时，弹窗要求用户确认后才继续，不静默默认 WGS84。

## 投影边界（2026-11-05 确认）

**输出侧**：限白名单——CGCS2000 地理（EPSG:4490）、CGCS2000 3° 高斯-克吕格（自动选带）、WGS84 UTM（自动选带）、Web Mercator。默认 CGCS2000。

**输入侧**：允许任意 EPSG 代码、`.prj` 文件或坐标声明，经 `pyproj` 校验后必须由用户显式确认。Xian80 / BeiJing54 允许输入，但强制用户显式提供七参数或转换网格，不允许用默认参数静默转换。

**内部量算**：不固定投影，按数据范围与量算类型自动选择并回显。

-   单带范围内：使用该带的 CGCS2000 3°GK（按图幅中心经度选带，中央经线 CM = round(lon / 3) × 3；徐州落在 EPSG:4548）。
-   跨带或省域以上：使用 CGCS2000 Albers（中央经线 105°E，标准纬线 25°N / 47°N）。面积量算用等积圆锥，形状与方位量算用等角圆锥。
-   Web Mercator 仅用于显示，禁止量算。

**回显与留痕**：自动选带结果必须回显且可覆盖（带号、中央经线、是否带 500 km 偏移与带号前缀）；凡涉及基准转换或输出非默认投影，须显式确认并记入元数据变换链。

**数据源坐标系（2026-11-09 确认）**：阿里 DataV GeoAtlas 的行政边界来源于高德开放平台，按 GCJ-02 处理；加载时纠偏到 WGS84，使用公开近似算法（精度约 1–2 m，偏移量尚未实测），纠偏方向与特征数记入元数据变换链。quotsoft 站点坐标为 WGS84，不纠偏。

**最终边界表述**：不做自定义投影定义与参数微调；输入可声明任意 CRS 并显式确认；输出限白名单；内部量算按数据范围自动选择并回显。

## 边界声明的意义

行业场景下必须主动说明「做通用专题制图，不承诺专业测绘精度」，否则会被追问数据准确性。每张图强制标注数据来源与更新时间，是制图规范的一部分。
