# 制图规范与审查

> 状态：已确认（2026-11-05）。十条例行清单、配色语义、审查失败路径与知识库落地均已确认，本文件无待确认项。

## 规范清单（审图员逐条判定）

1. 图名包含【区域 + 指标 + 时间】
2. 图例有分级断点与单位
3. 比例尺
4. 指北针
5. 数据来源 + 更新时间
6. 分级方法注明（自然断点 / 分位数 / 等间距 + 级数）
7. 坐标系注明（CGCS2000 或 EPSG 代码；输出默认 CGCS2000，见 [02-范围与边界.md](02-范围与边界.md)）
8. 配色语义正确：连续量 → 单色渐变；跨零量 → 发散配色；AQI → 国标六级固定色阶；禁止彩虹色
9. 中文无乱码：
   ```python
   plt.rcParams['font.sans-serif'] = ['Microsoft YaHei', 'SimHei']
   plt.rcParams['axes.unicode_minus'] = False
   ```
10. 缺失值处理说明

## 知识库落地（2026-11-05 确认）

- 十条规则以结构化 JSON 存储，驱动 PASS / FAIL 判定；结果确定、可测试、可 diff。
- RAG 只负责检索条文解释与修复建议，**不参与判定**，避免同一张图两次结论不同。
- 断网时退化为直接读取 JSON，判定结果不受影响。
- 检索的具体实现（本地嵌入或关键词索引）在 SPEC 阶段确定，不得引入联网依赖。

## 审查的失败路径（2026-11-05 确认）

渲染层**不得代填**以下四项，只能由 MapSpec 决定；缺失或不合规时审图员判 FAIL：

1. 图名要素（第 1 条：区域 + 指标 + 时间）
2. 分级方法与级数（第 6 条）
3. 配色语义（第 8 条）
4. 缺失值处理说明（第 10 条）

其余版式要素（图例分组、比例尺、指北针、来源注记、坐标注记）允许渲染层按 spec 补齐。

## 指令与规范的优先级（2026-11-05 确认）

分级处理，不一律服从、也不一律拒绝：

- **强制项，不可覆盖**：比例尺、数据来源与更新时间、坐标系注记、AQI 国标六级色阶。用户指令与之冲突时保持规范值，并向用户说明原因。
- **可调项，用户优先**：标题措辞、配色深浅（须在合规色阶范围内，如 PM2.5 浓度用单色渐变时调整深浅）、图例位置等。调整写入 `MapSpec.notes` 与审查报告。
- 用户指令触及强制项边界时，按强制项处理，不得静默偏离。
