# 产品定义与用户

> 状态：已确认（2026-11-05）。本文件只记录已确认的产品事实，变更需用户显式提出。

## 一句话定义

说一句话（或上传一份点位 / 统计数据），输出一张符合制图规范的、可直接进入报告和论文的成品专题图（PNG / PDF），并附一份制图说明与合规审查意见。

## 产品定位

- 领域：GIS / 空间数据 / 专题制图，行业场景。
- 面向：需要一张图但不会 GIS 的人——记者、教师、基层业务人员、规划院新人、学生。
- 核心差异：不是「画一张图」，而是「按制图学规范出一张图」。

## 价值锚点

GIS 的「最后一公里」：需要一张图的人，远多于会用 GIS 的人。现状只有两条路——学 ArcGIS（贵、难、装不上），或找人代做（几十到几百元、要等）。

## 项目背景

华为开发者大赛 · 江苏师范大学站（码道 Agent 创新赛题）。开发在码道 CodeArts 上完成。
