# 三 Agent 与协作协议

> 状态：已确认（2026-11-05）。本文件已无待确认项。

## \[1\] 数据管家 DataSteward

职责：解析用户意图 → 生成数据需求 → 加载数据 → 数据体检。

关键约束：

-   缺区域 / 时间 / 指标时必须反问，一次最多问 2 个问题。
-   不许自己猜一个默认值糊弄过去。

## 数据降级规则

2026-11-05 确认改为**两档自适应判定**，取代原先的固定站数阈值（≥15 成面 / 3–14 降级 / <3 放弃）：

判定依据只看两项：**有效站数 `n`**（剔除缺测后）与**空间覆盖度 `cover`**（站点凸包面积 / 研究区面积）。不做留一交叉验证。

-   通过（`n ≥ 10` 且 `cover ≥ 0.5`）：IDW 成面。
-   不通过：降级为点图 / 气泡图 + 城市面底色。
-   硬下限（`n < 3`）：放弃该指标，反问用户换指标或换区域。
-   字段缺失：换指标，并明确告知用户。

配套约束：

-   只在站点凸包内插值，凸包外不着色，图例注明「无站点覆盖区域未插值」，不做外推。
-   判定理由必须写入 `MapSpec.notes` 与审查报告，界面显示三行以内（站数、覆盖度、结论）。

## \[2\] 制图师 Cartographer

职责：接收数据摘要 + 需求，产出完整的 MapSpec。

关键约束：

-   分级方法与配色按规则自选，不硬编码。
-   分级方法选择规则：

| 数据特征 | 选择 |
| --- | --- |
| 右偏严重 | 分位数（quantile）或自然断点（jenks） |
| 近似正态、样本量小 | 等间距（equal\_interval） |
| 数值跨零 | 发散配色（diverging） |
| 类别型 | 定性配色 |

-   配色语义规则：AQI 必须用国标六级固定色阶；空气质量浓度用单色渐变（YlOrRd / YlGnBu）；绝不用彩虹色。

## \[3\] 审图员 Reviewer

职责：按制图规范清单逐条判定 PASS / FAIL，否决并给出修复建议（清单见 [07-制图规范与审查.md](07-%E5%88%B6%E5%9B%BE%E8%A7%84%E8%8C%83%E4%B8%8E%E5%AE%A1%E6%9F%A5.md)）。

关键约束：

-   不许改数据，只许改 spec。
-   只给意见，不自己动手画。

## 协作协议（在代码里写死）

-   审图员最多否决 2 轮。
-   第 2 轮仍 FAIL → 出图 + 附审查意见，绝不允许死循环。
-   全局最大轮次 8，超时 60 秒兜底。
-   返工上限是硬性保护，现场演示不允许卡死。

## 超时与兜底（2026-11-05 确认）

-   计时从用户提交起算，含数据加载、Agent 调用与渲染，按整体 60 秒计，不是每个环节各算 60 秒。
-   超时或达最大轮次：用当前 MapSpec 直接渲染出图，图角标注「审查未完成（超时）」，同时返回已完成的问题清单与缺失项。
-   不返回错误页，不返回空白图。

## 整体流程

```
用户输入
  → 信息不足则反问（最多 2 问）
  → 数据需求 → 加载 → 数据体检
  → 制图师产出 MapSpec
  → 渲染层出图
  → 审图员审查
      ├─ PASS → 输出图 + 制图说明 + 审查报告
      └─ FAIL → 返工（轮次 < 2）
                 轮次 = 2 → 出图 + 附审查意见



```
