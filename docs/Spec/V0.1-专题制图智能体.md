## 1. 目标

实现一条端到端链路：用户输入一句话（可选上传点位 / 统计数据）→ 三 Agent 循环产出 `MapSpec` → 确定性渲染层出图 → 审图员判定 → 输出 PNG / PDF、制图说明与审查意见。

核心约束：LLM 只做决策，不做计算、不写绘图代码；分级由 `mapclassify` 计算，出图由 `matplotlib` 绘制。

## 4. 预期行为

1. 输入缺区域 / 时间 / 指标时反问，一次最多 2 问，不猜默认值。
2. 数据体检返回自然语言 `summary`（站数、有效值、极值、完整度、插值建议），供 Agent 决策。
3. 插值判定按两档自适应：通过则 IDW 成面，否则降级点图 / 气泡图；只插凸包内，理由写入 `notes` 与审查报告。
4. 制图师输出完整 `MapSpec`，坐标与投影按投影边界处理，选带结果回显。
5. 渲染层按 spec 出图，补齐版式要素，中文正常。
6. 审图员按十条规范逐条判定；FAIL 进入返工，上限 2 轮；第 2 轮仍 FAIL 则出图 + 附意见。
7. 超 60 秒或达最大轮次，仍返回当前 spec 的图并标注「审查未完成（超时）」，附已完成的问题清单，不返回空白或错误页。
8. 用户修改标题 / 图例 / 配色等，只改 spec 后重渲染，秒级出新图。
9. 五个图种各可端到端跑通一次。
10. 断网时可用 `demo_data/` 完成演示。
11. 支持上传 CSV / GeoJSON / Shapefile(zip)；文件缺 CRS 时弹窗要求用户确认后才继续，不静默默认。
12. 支持 GeoTIFF 离线底图显示，不做栅格分析与重投影；其 CRS 与出图坐标系不一致时提示，不静默叠加。
