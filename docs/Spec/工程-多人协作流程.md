## 1\. 目标

让仓库拥有者以外的人能够在 GitHub 上提交代码：

1.  仓库由私有改为公开，任何人都可以 fork 并向 `main` 提交 Pull Request。
2.  `PINGNINGYI` 作为协作者加入，拥有 Write 权限，可推送分支、评审 PR。
3.  `main` 受 Rulesets 保护：禁止直接推送，变更必须经 PR 评审后合并；仓库拥有者可 bypass 自行合并。
4.  贡献流程有统一入口与模板，规则仍只在 [../工程规则.md](../%E5%B7%A5%E7%A8%8B%E8%A7%84%E5%88%99.md) 维护。

## 3\. 预期行为

1.  贡献者 fork 仓库后，在自有分支开发并向上游 `main` 发起 PR。
2.  打开 PR 时自动出现模板，要求填写关联 SPEC、自检命令与结果、独立验收记录。
3.  `main` 拒绝直接推送；PR 至少获得 1 位维护者批准、所有对话解决后才能合并。仓库拥有者 `dlg591103-cpu` 在 Rulesets 的 bypass list 中，可自行合并自己的 PR。
4.  `PINGNINGYI` 可评审 PR；`docs/facts/`、`docs/工程规则.md` 的改动需仓库拥有者批准。
5.  贡献者使用自己的 Git 身份提交，不冒用维护者身份，不提交密钥与真实用户数据。
