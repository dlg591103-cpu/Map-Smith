# 审图员契约与 qa_check 规则（SPEC T19）

> 状态：待验收。对应 SPEC V0.1 的 T19「规范规则库 + qa_check」，需求单称「T12 Reviewer」。
> 本文只写审图员实现契约与规则表，不复制产品事实；产品事实见 [docs/facts/07-制图规范与审查.md](../facts/07-制图规范与审查.md)。

## 1. 交付物

| 路径 | 作用 |
| --- | --- |
| `src/mapsmith/tools/qa_check.py` | 确定性规则引擎，逐条判定 R01-R10，不调用 LLM |
| `src/mapsmith/agents/reviewer.py` | 审图员入口，组合 qa_check、轮次控制、超时兜底 |
| `src/mapsmith/agents/prompts/reviewer.md` | 审图员 system prompt |
| `src/mapsmith/kb/reviewer_rules.json` | R01-R10 结构化知识库（只存元数据与修复提示） |
| `src/tests/test_reviewer.py` | 合规、缺来源、AQI 彩虹色、跨零单色、第 2 轮放行等用例 |

## 2. 输入兼容

本分支基线 `main` 尚无 `src/mapsmith/spec.py`，因此审图员不导入 spec 模型：

- `qa_check(spec, png=None)` 与 `review(...)` 接受 `dict` / 任意 `Mapping`，以及带 `model_dump()` 或 `dict()` 的 pydantic 模型。
- 只读取约定字段，未知字段原样忽略，便于后续 `spec.py` 合入后直接复用。
- 新增可选字段（不改动既有字段语义）：
  - `classification.unit`：图例单位。
  - `data_health`：`{nan_count, min, max, summary}`，数据体检结果。
  - `font`：`{sans_serif: [...], unicode_minus: false}`，渲染层字体配置回执。
  - `render_meta`：`{scale_bar, north_arrow}`，渲染层是否实际绘制版式要素的回执。
- 既有字段（`title`、`extent`、`layout`、`classification`、`palette`、`crs`、`notes`、`data_source_note`）保持事实文档定义。

## 3. qa_check 返回契约

```json
{
  "passed": false,
  "issues": [
    {
      "rule": "R05",
      "severity": "fail",
      "message": "数据来源含更新时间或日期：data_source_note 缺少更新时间或日期",
      "fix_spec_patch": {"data_source_note": "数据来源：<来源名称>；更新时间：<YYYY-MM-DD>"}
    }
  ],
  "checks": [],
  "rule_results": {"R01": "pass", "R05": "fail"},
  "summary": "确定性规则未通过：R05 ……",
  "rules_version": "1.0",
  "checked_at": "2026-11-09T00:00:00+00:00"
}
```

- `issues` 只含 `fail` / `warn`，`checks` 含 R01-R10 全量结果。
- `passed` 仅在没有任何 `fail` 时为 `true`；`warn` 不阻塞出图。
- `fix_spec_patch` 使用点号字段路径，可直接交给 `apply_spec_patch()` 应用。

## 4. 十条硬规则

| 规则 | 判定要点 | 失败时修复方向 |
| --- | --- | --- |
| R01 | `title`、`extent`、`layout` 存在；图名含区域 + 指标 + 时间 | 补 `title` / `extent` / `layout` 字段 |
| R02 | `layout.legend=true`，`classification.breaks` 非空，单位非空 | 补图例开关、断点、单位 |
| R03 | `layout.scale_bar=true`；`render_meta.scale_bar` 不得为 false | 改 spec 或提示渲染层补比例尺 |
| R04 | `layout.north_arrow=true`；`render_meta.north_arrow` 不得为 false | 改 spec 或提示渲染层补指北针 |
| R05 | `data_source_note` 非空且含日期 | 补来源与 `YYYY-MM-DD` 更新时间 |
| R06 | `classification.method` 与 `n` 已声明；breaks 数量为 `n-1` 或 `n`，严格递增 | 由 classify 重算或修正 n |
| R07 | `crs` 为 `EPSG:4326`、`EPSG:4490` 或 `CGCS2000` | 改输出坐标系 |
| R08 | AQI 用国标六级色阶；跨零用 diverging；连续量用单色渐变；禁止 jet/rainbow | 替换 `palette.scheme` |
| R09 | `font.sans_serif` 含 Microsoft YaHei / SimHei，`unicode_minus=false` | 补字体配置或提示渲染层 |
| R10 | `data_health.nan_count > 0` 时，`notes` 须含缺失/插补说明 | 在 spec 中补处理策略 |

判定只依据 spec 与渲染回执，不读原始数据，不调用 LLM。

## 5. reviewer 契约与返工轮次

```python
review(spec, png=None, data_summary=None, round_no=1,
       llm_callable=None, timeout=60.0) -> {
    "passed": bool,
    "round": int,
    "issues": [...],
    "summary": str,
    "allow_render": bool,
    "remaining_denials": int,
}
```

- `round_no` 是当前审查轮次，从 1 起。
- 第 1 轮 fail：`passed=false`、`allow_render=false`，返回 spec 修复建议，loop 进入返工。
- 第 2 轮 fail：`passed=false`、`allow_render=true`，按协议出图并附审查意见。
- `round_no > 8`：直接返回 `allow_render=true` 与 `LOOP` 问题，不继续循环。
- `llm_callable(system_prompt, payload)` 为可选软判钩子；软判结果统一降级为 `warn`，不改变 R01-R10 的 fail。
- LLM 软判超过剩余时间时抛 `ReviewTimeoutError`，由 loop 捕获并按「审查未完成（超时）」兜底出图；reviewer 自身不 sleep、不重试。

## 6. 与 loop 的接入方式

`loop.py` 尚未合入 `main`。合入后按以下方式调用，不需要改 reviewer 内部逻辑：

```python
from mapsmith.agents.reviewer import review

verdict = review(spec, png=png_path, data_summary=health, round_no=round_no)
if verdict["allow_render"]:
    render(spec)
    publish(verdict["summary"])
else:
    spec = apply_spec_patch(spec, verdict["issues"][0]["fix_spec_patch"])
```

loop 负责全局 8 轮计时与 60 秒总超时；reviewer 只负责单轮判定与可捕获异常。
