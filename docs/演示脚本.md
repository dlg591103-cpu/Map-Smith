# MapSmith 现场演示脚本（3 分钟）

> 目标：让评委在 3 分钟内看到「一句话 → 一张合规专题图」的完整闭环。
> 对应版本 v0.2.0。所有台词都已在本地实测通过。

---

## 0. 演示前 90 秒检查

在终端里依次确认：

```powershell
# 1) 服务在跑
curl http://127.0.0.1:8501/api/health
#   期望：{"status":"ok","llm_configured":true,"version":"V0.1"}

# 2) 浏览器开在 http://127.0.0.1:8501 ，侧栏底部显示「模型：已配置」

# 3) 点「新建对话」，确认是干净的开始
```

**兜底准备**：如果 LLM 抽风或网络不通，直接切「高级表单」——表单路径**不依赖模型**，
输入同样的区域/指标/图种即可出图。这是演示现场最可靠的保险。

---

## 1. 开场（30 秒）

> 大家好，这是 MapSmith。
>
> 它解决的问题很具体：**你需要一张能放进报告里的专题图，但不会 GIS。**
>
> 传统流程是「找数据 → 学 QGIS → 调样式 → 补图例比例尺 → 导出」，
> 快也要一两个小时，慢则半天。
>
> MapSmith 让你**说一句话**，几分钟内拿到一张**要素齐全、来源可追溯、经过规则审查**
> 的成品图。

操作：停在干净对话页，不要提前输入。

---

## 2. 场景一：一句话出图（60 秒）

**在对话框输入**（可直接复制）：

```
徐州 2026-11-01 的 PM2.5 分布
```

**点击发送后说**：

> 注意它没有直接画图——先分析这批数据够不够。

**看屏幕上的阶段提示**（解析需求 → 加载数据 → 生成制图方案 → 渲染地图 → 审查地图）。

**出图后，指着图讲**：

> 图上有：图名、分级图例（带单位 μg/m³）、比例尺、指北针、数据来源与更新时间、
> 坐标系、分级方法。
>
> 这几项目前是**自动补齐**的——因为制图规范不是你记得住才做，而是系统必须做。

**如果被问到站点为什么是点而不是面**：

> 因为徐州当天只有 5 个有效站点，覆盖率 50%。插值需要至少 10 个站、
> 50% 覆盖才算可靠，所以它**主动降级为点图**并写明原因——宁可如实降级，不硬做假插值。

---

## 3. 场景二：不止空气数据（45 秒）

**输入**：

```
做一个江苏省各市2025年人均GDP图
```

**出图后说**：

> 这是社会经济统计数据，数据源是开放 API 的全国榜单，覆盖 31 个省、200 个地级市、
> 243 个指标。
>
> 所以空气质量、GDP、人口、财政收入、城镇化率……**换指标就行，不用换工具**。

**顺手补充**：

> 这里顺便说明边界：**省级、地级市**都能自动取数；
> 再往下到区县，免费接口没有，要么上传 CSV，要么按次购买——我们不编数据。

---

## 4. 场景三：可以分几轮说（30 秒）

**输入**（故意只说半句）：

```
做个图
```

**它会追问**「想画哪个城市或区县」。**输入**：

```
浙江省
```

**它会继续追问指标。输入**：

```
城镇化率
```

**出图后说**：

> 用户不会一次说全，所以多轮补全是必须的。它记住前面说过的内容，
> 不会让你把「浙江省」再说一遍。

---

## 5. 场景四：为什么可以信（20 秒）

**点开结果下方的「制图说明」**：

> 每条决策都写下来了：为什么用点图不用插值、有效站点几个、缺失怎么处理的。
>
> 而且所有参数都沉淀成一份 spec（JSON），**改一个字段就能重渲染**，
> 不用从头再来。

**如果有审查意见，指着说**：

> 图上还跑了一遍 10 条确定性硬规则——图名有没有要素、图例有没有单位、
> 比例尺在不在、来源有没有更新时间……不合格会自动返工，最多两轮，不会无限循环。

---

## 6. 收尾（15 秒）

> 总结一下：**说一句话，出一张能用、能查、能改的图。**
>
> 代码开源，地址在仓库 README。

停在这里，把提问时间留给评委。

## 备用：可能被问到的问题

| 问题 | 回答要点 |
|---|---|
| **数据准不准？** | 图上有来源与更新时间，如实标注；数据不足时主动降级并说明，不硬做插值。 |
| **AI 乱画怎么办？** | 图种、分级、配色不是模型自由发挥，走的是确定性规则；模型只负责理解需求。 |
| **断网能用吗？** | 核心演示数据内置，断网可演示徐州多日空气、江苏各市 GDP、区县 PM2.5。 |
| **能不能加别的指标？** | 统计类走开放榜单（243 个）；区县级需要上传 CSV 或按次购买。 |
| **和 ChatGPT 画图有什么区别？** | 它出图不管规范；这里图名/图例/比例尺/来源/坐标系全部按规则补齐并审查。 |
| **支持哪些图种？** | 分级设色、点图/气泡、IDW 插值、缓冲区、叠加裁剪五类。 |
| **为什么市级统计要积分？** | 区县级数据在数据源侧是付费内容（1 积分买断一个指标 365 天）；省级免费。 |

## 演示节奏提醒

| 时间 | 内容 | 关键动作 |
|---|---|---|
| 0:00–0:30 | 开场 | 停在干净对话页 |
| 0:30–1:30 | 一句话出图 | 徐州 PM2.5 |
| 1:30–2:15 | 统计数据 | 江苏人均 GDP |
| 2:15–2:45 | 多轮对话 | 「做个图」→「浙江省」→「城镇化率」 |
| 2:45–3:00 | 可解释 + 收尾 | 点开制图说明 |

**如果时间被压缩到 1 分钟**：只做「开场 + 徐州 PM2.5 + 一句总结」。
**如果时间充裕到 5 分钟**：加「高级表单」（展示五类图种下拉）、「历史会话」（刷新不丢）。
